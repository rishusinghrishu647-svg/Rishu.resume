# Rishu Singh — Resume Website

A responsive static resume website built with HTML, CSS, and JavaScript.

## Files
- `index.html` — content and page structure
- `styles.css` — layout, colors, responsive design, and animations
- `script.js` — navigation, contact button, scroll effects, print-to-PDF, and demo login

## Before publishing
1. Open `script.js`.
2. Replace `YOUR_EMAIL@example.com` with the email address you want employers to use.
3. In `index.html`, update your expected graduation year and any details you want to add.
4. Check that you are comfortable publishing all contact details publicly.
5. Open `index.html` in Chrome to preview.

## Run locally
Double-click `index.html` to open it in your browser. No build tools are required.

## Resume download
Click **Download resume** and choose **Save as PDF** in the browser print dialog. The current print dialog uses the website content; for a polished one-page CV, you may want to also keep a dedicated PDF resume file in the repository and link to it.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/
2. Create a new public repository, for example `rishu-resume`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository's root.
4. Open the repository's **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)` folder, then save.
7. Wait for the Pages deployment to finish. Your website address will look like:
   `https://YOUR-GITHUB-USERNAME.github.io/rishu-resume/`

GitHub's interface can change; consult https://docs.github.com/pages if a menu label differs.

## Important limitations
- The login UI is a visual demo only. It is not secure authentication and does not store or validate accounts.
- The contact link opens the visitor's email application. It does not send email directly from the website.
- GitHub Pages hosts static files. Secure accounts, databases, and server-side form processing need a backend or third-party service.
- This website includes only details previously provided. Verify all details and replace placeholders before publishing.
